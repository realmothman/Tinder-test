# 📱 Estudo de Automação do Tinder

## Objetivo
Explorar repositórios de automação do Tinder, identificar linguagens e padrões comuns para fins educacionais.

## 📊 Linguagens por Relevância

### 1. **Python** 🏆 DOMINANTE
- **Uso**: Selenium, API wrappers, IA/ML, deep learning
- **Popularidade**: ~70% dos projetos
- **Libs principais**: Pynder, undetected-chromedriver, TensorFlow
- **Exemplos**: auto-tinder (567★), TinderBotz, willhughes11/tinder-ai-auto-swiper

### 2. **JavaScript/Node.js** 📌
- **Uso**: npm packages, web automation, backends leves
- **Libs principais**: tinder npm, Selenium webdriver, Appium
- **Casos de uso**: Automação web, bots Discord/Telegram

### 3. **Java** 🔧
- **Uso**: Backends robustos, API servers
- **Framework**: Spring Boot
- **Exemplo**: jayram0402/Tinder-Automation (Spring Boot + React)

### 4. **Swift** 📲
- **Uso**: Automação iOS nativa
- **Libs**: VerticalCardSwiper, Shuffle

### 5. **PHP** 🌐
- **Uso**: Plataformas CMS dating, backends web
- **Casos de uso**: Clones de plataforma

Automação não autorizada viola os Termos de Serviço do Tinder e pode resultar em banimento de conta. Este estudo é apenas **educacional**.
