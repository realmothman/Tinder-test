## 🎯 CORE COMPONENTS

### `tinder_automation.py` (470 lines)
**Purpose**: Real browser automation
```python
class TinderAutomation:
    - login(email, password, 2fa_support)
    - get_matches(limit=50)
    - send_message(match_id, message)
    - get_conversation(match_id)
    - swipe(direction, count)
    - close()
```
**Features**:
- Selenium + undetected-chromedriver (anti-detection)
- Random delays (2-10s between actions)
- User-agent spoofing
- Mock mode for testing
- 2FA support

### `real_bot_system.py` (380 lines)
**Purpose**: Orchestrate automation + learning + analysis
```python
class RealBotSystem:
    - login()
    - process_match(match)
    - run_once(limit=5)
    - run_continuous(interval, max_iterations)
    - get_analysis_summary()
    - save_activity()
    - close()
```
**Pipeline**:
1. Generate intelligent opening (adaptive)
2. Send message (real browser)
3. Wait for response (30-60s)
4. Collect conversation
5. Analyze with 3 frameworks
6. Update adaptive model
7. Save results

### `adaptive_opening_generator.py` (450 lines)
**Purpose**: Learn from history, generate personalized openings
```python
AdaptiveOpeningMessageGenerator:
- generate_opening(profile) → (message, confidence_score)
- get_patterns() → emoji%, question_rate, success_rate
- extract_common_topics() → list of topics
- get_profile_success_mapping() → which demos respond best
```

### `tinder_bot_example.py` (480 lines)
**Purpose**: Data models + anthropological analyzers
```python
Profile, Message, Conversation (dataclasses)

HomophilyAnalyzer:
  - Detects demographic similarity
  - Score 0.0-1.0 (1.0 = very similar)
  
GenderAnalyzer:
  - Extracts gender-based patterns
  - Response times, message length by gender
```
