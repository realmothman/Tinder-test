# 📋 Metodologia Prática: Analisar Tinder Antropologicamente

## Como COMEÇAR SUA ANÁLISE AGORA

---

## FASE 1: COLETA DE DADOS ETICAMENTE (2-4 semanas)

### Passo 1: Documentar Seus Próprios Dados

**O que fazer:**
```
1. Abra Tinder
2. Tire screenshots das suas interações
   ├─ Perfis que você viu
   ├─ Quem você deu like/pass
   ├─ Matches resultantes
   ├─ Conversas iniciais
   └─ Se encontrou, como foi?

3. Documente em planilha:
   ├─ Nome/idade/profissão/localização do match
   ├─ Resumo da bio
   ├─ Que fotos eles tinham
   ├─ Como vocês conversaram
   ├─ Fizeram encontro? Como foi?
   └─ O que você aprendeu com essa pessoa?

4. Padrões a procurar:
   ├─ Você tem tipo preferido?
   ├─ Padrão de gênero, raça, idade, classe?
   ├─ Eles são similares a você? (Homophilia)
   ├─ Como você se apresentou? (Performatividade)
   └─ Como a conversa começou? (Rituais)
```

**Exemplo de entrada:**
```
Match #1: Marina, 28, Jornalista, Vila Mariana
Bio: "Amo viajar, cinema francês, coffee shops"
Fotos: Viagem à Europa, em eventos, close-up
Seu primeira mensagem: "Qual seu filme francês favorito?"
Dela: "Truffaut! Você tem bom gosto 😊"
Vocês encontraram? Sim, café na Paulista
Resultado: 3 encontros, depois ela saiu com outra pessoa
Análise: Você combinaram em capital cultural (cinema, viagens)
```

### Passo 2: Entrevistar Seus Matches (Com Consentimento!)

**Perguntas Antropológicas para Fazer:**

**Sobre Performance:**
```
1. "Como você escolheu suas fotos para o Tinder?"
   → Elas são representativas de você IRL?
   
2. "Como você escreve sua bio?"
   → Você tenta ser engraçado? Intelectual? Sexy?
   
3. "Você acha que pareço no Tinder igual na vida real?"
   → O que é diferente?
```

**Sobre Seleção:**
```
4. "Qual é seu 'tipo' no Tinder?"
   → Raça, altura, corpo, profissão?
   → Por que esse tipo?
   
5. "Você acha que tem 'preferência' ou é aquilo que culturalmente é atraente?"
   → Autoconsciência sobre homophilia/padrões de beleza
```

**Sobre Experiência:**
```
6. "Como foi seu experiência no Tinder?"
   → Como se sente sendo 'swiped'?
   → Qual é a diferença de ser homem/mulher no Tinder?
   
7. "Qual foi seu encontro mais estranho? Por quê?"
   → Expectativa vs realidade
   
8. "Você acha que Tinder mudou sua forma de namorar?"
   → Impacto social/cultural
```

**Como Fazer:**
- Peça por WhatsApp/mensagem depois do match
- Prometa anonimato ("Vou usar dados para pesquisa, sem nomes")
- Faça por escrito (eles podem pensar melhor)
- Agradeça genuinamente

### Passo 3: Observar Padrões Estruturais

**Que dados você pode ver no Tinder:**
```
✅ Seus próprios swipes (quem você deu like/dislike)
✅ Seu próprio perfil (quanto tempo recebe matches?)
✅ Fotos que as pessoas mostram
✅ Bios (como se descrevem)
✅ Mensagens iniciais (que rituals usam?)
✅ Velocidade de resposta

❌ Você NÃO pode:
  └─ Ver swipes de outras pessoas (sem hacking)
  └─ Acessar dados de algoritmo da Tinder
```

**Documenta no seu caderno:**
```
Semana 1:
├─ Perfis vistos: 150
├─ Likes dados: 30 (20% - você é seletivo/a?)
├─ Matches recebidos: 15
├─ Matches que iniciaram conversa: 8 (53%)
├─ Conversas que viraram encontro: 2 (25%)
└─ Análise: qual era critério para "like"?

Padrões Encontrados:
├─ Você deu like mais em qual raça/gênero?
├─ Fotos que recebem mais match (que tipo)?
├─ Primeiro mensagem que funciona melhor?
└─ Tema das conversas bem-sucedidas?
```

## FASE 2: ANÁLISE TEMÁTICA (2-4 semanas)

### Método: Análise de Conteúdo Qualitativa

**O que você está procurando:**

#### 1. HOMOPHILIA (Semelhança)
```
Pergunta: "Com que tipo de pessoa você matcher?"

Análise:
├─ Raça: você match mais com mesma raça? Qual?
├─ Idade: margem de idade que você aceita?
├─ Classe: profissões dos seus matches (executivos vs artistas?)
├─ Localização: bairro "chique" vs periférico?
├─ Educação: nível de estudo sinalizado na bio?
├─ Valores: política, religião, estilos de vida?

Exemplo de Achado:
"Descobri que 70% dos meus matches são brancas, 
80% tem educação superior, 
60% moram na zona oeste da cidade. 
Isso reflete quem eu sou, ou reflete quem está em Tinder?"
```

#### 2. PERFORMATIVIDADE (Como se apresentam)
```
Pergunta: "Como pessoas constroem sua imagem?"

Análise:
├─ Fotos: sozinho, com amigos, em viagem, piscina?
├─ Filtros/edição: quanto usam?
├─ Bio: honestos ou "vendem" fantasia?
├─ Emojis/linguagem: casual, sofisticado, sexy?
├─ O que deixam para fora? (profissão? amor-próprio?)

Comparação com Realidade:
├─ Qual é a pessoa vs qual é a performance?
├─ Eles reconhecem isso?

Exemplo de Achado:
"Homens que colocam fotos de carro em perfil 
frequentemente mensagens sobre carros primero.
Sinalizam 'status econômico' mas é o primeiro tópico?"
```

#### 3. CAPITAL ERÓTICO (Quem é "atraente"?)
```
Pergunta: "Por que algumas pessoas recebem mais matches?"

Análise:
├─ Corporalidade: corpo conforme padrão hegemônico?
├─ Gênero: mulheres precisam ser sexy, homens precisam ser viril?
├─ Raça/etnicidade: qual tem "premium"?
├─ Juventude: idade importa? (especialmente para mulheres?)

Seus Dados:
├─ Quantos matches você recebe por dia?
├─ Qual é "tipo" mais buscado?
├─ Existe "racial wage gap" no Tinder?
  (pessoas negras recebem menos matches?)

Entrevistas:
└─ Pergunte ao matches: "Como você se sente sendo avaliado/a visualmente?"
```

#### 4. DINÂMICA DE GÊNERO & PODER
```
Pergunta: "Como poder sexual é distribuído?"

Análise:
├─ Quem mensageia primeiro? (expectativa de gênero)
├─ Quem propõe encontro? (risco é feminizado)
├─ Mensagens sexuais são aceitas por quem?
├─ Velocidade de escalonização (sexualização rápida?)
├─ Experiência de "rejeição" (como cada gênero processa?)

Exemplo:
"Homens frequentemente mensageiam com foto nude pedindo feedback.
Mulheres raramente faz isso. 
Isso reflete educação sexual? Padrões culturais? Risco percebido?"
```

#### 5. RITUAIS & SEQUÊNCIAS
```
Pergunta: "Como relacionamento nasce no Tinder?"

Análise:
├─ Primeira mensagem: "Oi" vs piadas vs perguntas?
├─ Escalation: quando pede encontro?
├─ Encontro onde: bar, café, casa?
├─ Primeira conversa: que tópicos?
├─ Physical: quando toca? Beija?

Padrão Ritual:
"Match → Like → Mensagem Inicial → [3-5 mensagens] → 
Encontro → Conversa IRL → Avaliação → 
Próximo Match ou Relacionamento"

Exemplo:
"Pessoas de classe alta tendem a propor encontro em restaurante sofisticado.
Pessoas de classe média/baixa em bar casual.
Capital econômico estrutura até rituals de encontro."
```

## FASE 3: ESCRITA & SÍNTESE (2-3 semanas)

### Estrutura para Escrever Seus Achados

#### Exemplo de Artigo/Ensaio

```
TÍTULO: 
"Homophilia e Capital Erótico no Tinder: Uma Auto-etnografia 
de Preferências Amorosas em São Paulo"

INTRODUÇÃO:
├─ Por que Tinder é interessante antropologicamente?
├─ O que você pretendia estudar?
└─ Como você fez a pesquisa?

METODOLOGIA:
├─ Participantes: quantos matches foram entrevistados?
├─ Período: quanto tempo coletar dados?
├─ Métodos: auto-etnografia, screenshots, entrevistas
└─ Ética: como manteve anonimato?

ACHADOS:

1. Homophilia em Ação
   ├─ Dados: 70% dos meus matches eram similares a mim
   ├─ Análise: isto é "atração natural" ou reprodução de sistema?
   └─ Discussão: como isso afeta segregação/desigualdade?

2. Diferenças de Gênero
   ├─ Dados: [seus dados específicos]
   ├─ Achado: [padrão que você encontrou]
   └─ Implicação: [o que isso significa?]

3. Performance & Autenticidade
   ├─ Dados: [exemplos de pessoas que eram diferentes IRL]
   ├─ Análise: quanto é "verdadeiro"? Pode haver verdade em performance?
   └─ Teoria: como Goffman/Butler explicam isso?

DISCUSSÃO:
├─ O que seus achados revelam sobre nossa sociedade?
├─ Como Tinder reflete ou reifica estruturas sociais?
├─ Implicações éticas de algorítmica de matching?

CONCLUSÃO:
└─ "Tinder não é 'neutral technology' - reifica capital erótico 
   e reproduz homophilia que estrutura segregação social"
```

## 🎯 FRAMEWORKS RECOMENDADOS POR ÂNGULO

### Se seus dados mostram HOMOPHILIA forte
→ Use **Bourdieu (Capital) + McPherson (Homophily)**
```
Tese: "O Tinder reifica desigualdades estruturais 
através de matching baseado em homophilia"
```

### Se seus dados mostram DIFERENÇAS DE GÊNERO
→ Use **Butler (Performatividade) + Heteronormatividade**
```
Tese: "Dinâmicas hetero-normativas estruturam 
sexualidade e poder no Tinder"
```

### Se você quer análise MAIS CRÍTICA
→ Use **Debord (Espetáculo) + Commodificação**
```
Tese: "Tinder como espetáculo: a reificação de pessoas 
como commodidades consumíveis"
```

### Se quer abordagem MAIS DESCRITIVA
→ Use **Netnografia**
```
Tese: "Uma auto-etnografia de matching no Tinder: 
rituals, performances e negoções de intimidade"
```
